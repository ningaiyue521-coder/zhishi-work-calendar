# 知时 · Windows 工作日历

一个原生 Windows 工作记录与提醒工具：从当前工作窗口和可见通知中收集候选文字，结合消息上下文整理待办、日程和准备事项，保留原文并在合适的时候提醒。

> 当前版本：0.2。飞书前台文字已有实际采集验证；微信的聊天正文采集尚未打通，QQ、钉钉等尚未验收。通用识屏不等于所有软件的完整后台消息接入。

## 功能

- 前台窗口文字读取，必要时使用 Windows 本机中文 OCR。
- 中文日期时间识别；时间含糊的安排进入待核对。
- 同一会话的后续补充可关联改期、取消或完成，自动更新可撤销。
- 可配置兼容 Chat Completions JSON 模式的云端模型，分析本人相关性、工作进展和准备事项。
- 工作记忆保存来源、原文和处理结果；准备事项可以勾选完成或另外安排时间。
- 本机月历、待核对列表、托盘运行、提醒弹窗和 ICS 导出。
- 默认排除 Codex / ChatGPT、程序自身以及登录、密码窗口。

## 构建和运行

需要 Windows 10/11 x64、可用的 .NET Framework 4.8/WPF 和 Windows OCR 组件。没有额外的 NuGet、Node.js 或 Python 依赖。

在仓库目录运行 Windows PowerShell：

```powershell
.\build.ps1
```

脚本使用 Windows 的 .NET Framework 编译器，生成并测试：

- `WorkCalendar.exe`：主程序。
- `CaptureWorker.exe`：窗口采集进程，必须与主程序放在同一目录。
- `qa/`：仅供本地验证的测试程序与输出，不提交到 Git。

双击 `WorkCalendar.exe`，打开“采集设置”，填写自己的姓名或群昵称，以及服务商的 API 地址、模型名和 API Key。点击“测试云端连接”，通过后启用云端推理并保存，再点击“开始记录”。

API 地址支持 `https://api.example.com/v1` 这样的基础地址或完整的 `/chat/completions` 地址。示例域名不能直接调用；请自行配置自己的服务。仓库不提供任何真实账户配置或密钥。关闭云端功能时，本机时间识别、日历、手动录入和提醒仍然可用。

自动记录开启后每 8 秒采集一次。也可在工作窗口按 `Ctrl + Alt + Space` 单次识别。关闭主窗口后程序留在系统托盘；右键托盘或在设置中选择“彻底退出”才会停止程序。

## 行为示例

以下均为虚构示例：

| 输入 | 处理 |
| --- | --- |
| 明天下午三点开会 | 有可信消息日期时，记入明天 15:00，默认提前 15 分钟提醒 |
| 明天下午拉会 | 记在明天，保留“下午、时间待定”，安排核对提醒 |
| 会议改成下午四点 | 消息时间可信、同一会话且目标明确时更新原会议 |
| 会议取消了 | 关联原事项并移出日历，保留原文和撤销记录 |
| 报告已经发给客户 | 目标明确时标为完成，工作进展可记入工作记忆 |

没有消息发送日期的屏幕内容可能是历史记录。程序不会将其直接作为可信的具体时间提醒，也不会凭空把“下午”补成 15:00。无法确定目标的改期和取消进入待核对。

## 数据与隐私

运行后才会生成 `data/state.json`，其中包含本机设置、工作原文、日程、待分析消息和历史记录。保存时保留 `state.json.bak`。API Key 使用 Windows DPAPI 加密，绑定当前 Windows 账户；聊天与日程等其他本机数据并未整体加密。

截图仅在内存中用于本机 OCR，不保存、不上传。**启用云端后，候选工作文字、来源、有限的同会话上下文、相关日程和配置的姓名会发送到用户指定的 API。** 可以随时暂停采集、关闭云端推理或增加排除程序。

`data/`、`qa/`、可执行文件、截图、日志及本机配置均不应提交。此仓库使用源码文件白名单，并提供发布检查脚本：

```powershell
.\scripts\Test-PublishSafety.ps1
```

该脚本检查 Git 暂存内容的路径和常见敏感信息特征，不读取运行数据，也不调用网络。它不能替代人工检查。反馈问题时请使用虚构输入和脱敏信息，不要附带实际聊天、数据备份、API Key 或设置页截图。

## 当前限制

- 只能读取可访问的前台内容及尝试读取可见通知；最小化、未打开的会话、消失的通知和自绘界面可能读不到。
- 飞书前台采集通过不代表全部飞书消息、群聊历史或后台通知都已接入。
- 微信当前版本的窗口文字接口不提供聊天正文，专门的识屏适配仍需完善。
- 云端协议通过模拟服务测试；实际效果取决于自行配置的服务和模型。
- 睡眠、关机或程序彻底退出期间不能提醒；恢复运行后可补提醒最近一天的事项。
- 尚未配置开机自启、第三方日历同步或多设备同步。

## 验证

`build.ps1` 运行 65 项核心及工作流检查，覆盖中文时间边界、去重、持久化、改期取消、撤销、跨会话隔离、来源排除、提醒、ICS、DPAPI 及模拟 API 协议。

可选的桌面流程验收：

```powershell
.\WorkCalendar.exe --qa-pipeline
```

该模式启动约 20 秒的虚构消息窗口，在独立数据目录中验证“开会 → 改期 → 取消 → 提交报告 → 弹窗提醒”。结果写入 `qa/pipeline-result.json`，不修改正式 `data/`。测试模式与合成数据不能替代真实软件适配验收。
